## 2. Privacy Policy

### Data Collected
Bugle Bot collects and stores only the minimal data necessary to function across multi-server environments:
- **Server IDs & Channel IDs:** To deliver scheduled daily prompts and manage submissions in designated channels.
- **User IDs:** To attribute photo submissions, select co-winners, and manage leaderboards/prompts.

### Data Usage
All collected data is used strictly for bot operations (prompt processing, submission tracking, and daily cleanups). We do **not** sell, share, or monetize any user or server data.

### Data Retention & Deletion
- Temporary submission data is automatically cleaned up during scheduled database maintainence.
- Server owners can remove all stored server configuration data at any time by kicking or removing Bugle Bot from their server.
- Users may request data deletion by contacting the developer directly.

### Contact Information
For questions or data removal requests regarding Bugle Bot, contact the developer via Discord or GitHub.
